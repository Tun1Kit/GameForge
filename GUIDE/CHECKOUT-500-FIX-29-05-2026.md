### LỖI 1 — 8 trường giao hàng bị @Transient

**File:** `src/main/java/com/gamestore/entity/Order.java`

**Vấn đề:**
Các trường `paymentMethod`, `fullName`, `phone`, `address`, `province`, `district`, `ward`, `notes`
được đánh dấu `@Transient` → Hibernate BỎ QUA hoàn toàn, không INSERT/UPDATE vào DB.

**Trạng thái trước khi fix:**
```java
@Transient
private String paymentMethod;
@Transient
private String fullName;
// ... 6 trường khác
```

**Trạng thái sau khi fix:**
```java
@Column(name = "paymentMethod", length = 50)
private String paymentMethod;

@Column(name = "fullName", length = 255)
private String fullName;
// ... 6 trường khác với @Column tương ứng
```

**Database đã thêm (user tự chạy ALTER TABLE):**
```sql

ALTER TABLE [dbo].[orders] ADD [fullName] [nvarchar](255) NULL;
ALTER TABLE [dbo].[orders] ADD [phone] [nvarchar](50) NULL;
ALTER TABLE [dbo].[orders] ADD [address] [nvarchar](500) NULL;
```

**File:** `src/main/java/com/gamestore/controller/CheckoutController.java`

**Vấn đề:**
Endpoint `/api/promo/validate` cho phép chạy raw SQL bất kỳ qua prefix `SQL:`:


### LỖI 4 — Exception trả HTML thay vì JSON

**File:** TẠO MỚI `src/main/java/com/gamestore/config/GlobalExceptionHandler.java`

**Vấn đề:**
Khi exception xảy ra trong `@ResponseBody` method mà không được `try/catch` bắt, Spring MVC fallback về default error handling — trả về HTML error page (`<!doctype html>...`) thay vì JSON. Browser parse HTML → `SyntaxError: Unexpected token '<'`.

**Giải pháp:** Tạo `@ControllerAdvice` để bắt mọi exception từ API endpoint và trả JSON:

```java
package com.gamestore.config;

import org.springframework.http.HttpStatus;
import org.springframework.http.ResponseEntity;
import org.springframework.web.bind.annotation.ControllerAdvice;
import org.springframework.web.bind.annotation.ExceptionHandler;
import org.springframework.web.bind.annotation.ResponseBody;

import javax.servlet.http.HttpServletRequest;
import java.util.HashMap;
import java.util.Map;

@ControllerAdvice
public class GlobalExceptionHandler {

    @ExceptionHandler(Exception.class)
    @ResponseBody
    public ResponseEntity<Map<String, Object>> handleAllExceptions(
            Exception ex, HttpServletRequest request) {

        // Chỉ xử lý API endpoint — trả JSON
        if (request.getRequestURI().startsWith("/api/")) {
            Map<String, Object> response = new HashMap<>();
            response.put("success", false);
            response.put("message", "Lỗi máy chủ: " + ex.getMessage());
            ex.printStackTrace();
            return ResponseEntity.status(HttpStatus.INTERNAL_SERVER_ERROR).body(response);
        }

        // Request khác → rethrow để Spring xử lý bình thường
        return null;
    }
}
```
